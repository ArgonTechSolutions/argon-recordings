# Output and evidence contract

For a demo, emphasize what was demonstrated, relevant code/slide states, limitations and next steps. For a meeting, emphasize conclusions, decisions, unresolved questions and explicitly assigned actions. Keep output in the requested language. A source reference can look like `[00:42–00:48](<returned source link with at=42>)`; screenshot references also name the exact `frame:…` or `asset:…` ID and actual time. Do not expose API filesystem paths or credentials.

The optional machine-readable format is `argon-summary-v1`, implemented by [summary_contract.py](../scripts/summary_contract.py). Generate schemas with `python summary_contract.py schema`; validate with `python summary_contract.py check REPORT EVIDENCE CURRENT_REFERENCE`. All three inputs are local JSON files, at most 16 MiB each. `CURRENT_REFERENCE` is the final recording evidence snapshot expressed as a source reference, not a cached starting snapshot. Use the full recording interval in the reference and `scope` for the requested summary interval. A local evidence ledger contains the exact transcript pages received (including requested and returned cursors), source-relative image metadata, recipe versions, SHA-256 of retrieved bytes and an explicit inspection record. It contains source content; handle it as private recording data, not reusable plugin instructions. Do not put it in Git.

The report has `reference`, `scope`, `language`, `coverage` (`complete` or `partial`), `limitations`, `citations` and typed `items`. A citation identifies an exact segment or inspected image and its source interval. Items have `kind` (`summary`, `chapter`, `decision`, `action`, `question`), `basis` (`explicit`, `inference`, `unresolved`), `text`, citation IDs and optional action `owner`/`due`. Owner and due values each carry an exact source quote and citation IDs; the literal value must occur in that quote. This catches ungrounded strings, not misleading paraphrases or semantic misassignment. Semantic review must still verify that the cited words assign that person/date to that action. Do not populate a field merely to satisfy a schema.

Partial coverage needs an explicit reason. A complete report requires the transcript cursor chain to terminate. The validator rejects stale versions, cross-recording/source references, broken cursor chains, duplicate IDs, out-of-range citations, uninspected image citations, unsupported owner/date literals and visual observations without inspected images. Empty or missing speaker/visual evidence is a limitation when the requested output depends on it. Prompt-injection resistance and semantic accuracy require actual agent evaluation; schema validation alone cannot establish either.
